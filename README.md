# Bootverhuur-app

Klikbaar prototype van een boekingsapp voor een bootverhuurbedrijf. Klanten zoeken een datum en tijd, kiezen een boot, voegen extra's toe, vullen hun gegevens in en krijgen een bevestiging.

Het bedrijf "Wilgenhaven", de boten, de prijzen en de bezette tijden zijn voorbeelden. Er wordt niets echt geboekt, betaald of gemaild.

## Bekijken

Open `index.html` in je browser. Er is geen installatie nodig.
